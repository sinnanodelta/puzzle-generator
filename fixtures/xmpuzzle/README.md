# BurrTools example puzzles

Test fixtures for the `.xmpuzzle` importer (`crates/puzzle-core/src/xmpuzzle.rs`).
The files are unchanged, gzipped copies of `examples/*.xmpuzzle` from the BurrTools 0.6.3
source tarball:

- URL: https://sourceforge.net/projects/burrtools/files/burrtools/0.6.3/burrtools-0.6.3.tar.gz/download
- tarball sha256: `7354804f41a7326c36bf5f4b0b4c8d39c683ce522700192fb05d8436b9da93ff`

| File | Designer (from `examples/README`) |
|---|---|
| `AlPackino.xmpuzzle` | Ronald Kint-Bruynseels |
| `CubeInCage.xmpuzzle` | Mineyuki Uyematsu |
| `DraculasDentalDesaster.xmpuzzle` | Ronald Kint-Bruynseels |
| `PelikanBurr.xmpuzzle` | Dic Sonneveld |
| `DemoMirrorParadox.xmpuzzle` | Andreas Röver (user-guide demo) |
